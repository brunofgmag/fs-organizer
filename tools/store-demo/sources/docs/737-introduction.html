737-800 Introduction

Welcome

The Halcyon 737-800 models the short-field, winglet-equipped variant with a 189-seat cabin.

This introduction covers installation, the EFB and the first flight.

Installation

Keep the folder name halcyon-aircraft-737-800. Livery packs and the sound pack look for it.

The EFB

Weights, fuel, ground services and failures are set from the tablet on the captain's side.
